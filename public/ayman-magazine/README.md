# مجلة أيمن الحسّام التفاعلية — AYMAN AL HUSSAM Magazine

مجلة أعمال إبداعية عربية تُقرأ من اليمين إلى اليسار:
- **على الكمبيوتر:** كتاب بصفحتين متقابلتين تتقلب صفحاته بالسحب أو النقر أو أسهم لوحة المفاتيح.
- **على الجوال:** صفحة واحدة في كل مرة تُسحب جانبيًا.
- **في كل الأحوال:** يمكن فتح أي عمل بملء الشاشة وتكبيره بالعجلة أو بإصبعين أو بالنقر المزدوج.

المجلة ملفات ثابتة (HTML + CSS + JavaScript) **بلا أي مكتبات أو خطوة بناء**، وكل المسارات فيها نسبية.

## التشغيل محليًا

**أسرع طريقة:** افتح `index.html` مباشرة في المتصفح (نقر مزدوج)، فالمجلة تعمل دون خادم.

**بخادم محلي (الأقرب لبيئة النشر):**

```bash
cd ayman-magazine
npx serve .                # أو: python3 -m http.server 8000
```

ثم افتح `http://localhost:3000` (أو `:8000`).

## الخطوط

تستخدم المجلة خمسة خطوط مجانية (رخصة SIL Open Font License):
- Reem Kufi
- Markazi Text
- Aref Ruqaa
- Cormorant Garamond
- IBM Plex Sans Arabic

**افتراضيًا:** يحمّلها `fonts/fonts.css` من Google Fonts. هذا يعمل على Vercel وعلى أي جهاز متصل بالإنترنت.

**لاستضافتها داخل المجلد نفسه بلا أي طلب خارجي (موصى به للنسخة النهائية):**

```bash
cd ayman-magazine
node fonts/download-fonts.mjs      # Node 18 أو أحدث، يحتاج إنترنت مرة واحدة فقط
```

يفعل السكربت شيئين:
1. ينزّل ملفات `.woff2` إلى مجلد `fonts/`.
2. يعيد كتابة `fonts/fonts.css` بقواعد `@font-face` محلية.

لا يتغيّر شيء في التصميم، لأن أسماء الخطوط وأوزانها هي نفسها. وإذا لم تشغّله، تبقى المجلة سليمة بالخطوط من Google.

## الدمج في موقع Next.js على Vercel

### 1) انسخ المجلة إلى `public`

انسخ المجلد كما هو إلى موقعك:

```
your-next-site/
└── public/
    └── ayman-magazine/     ← محتوى هذا المجلد (يمكن حذف nextjs-integration منه)
```

بعد النشر تعمل المجلة مباشرة على:

```
https://ayman-showroom.vercel.app/ayman-magazine/index.html
```

> **مهم:** افتح المجلة دائمًا بالمسار الكامل `.../ayman-magazine/index.html`.
> Next.js لا يقدّم `index.html` تلقائيًا للمسار `/ayman-magazine`، والمسارات النسبية تحتاج أن يكون الملف داخل مجلده.

### 2) اختر طريقة الوصول إليها من `/magazine`

**الخيار (أ) — صفحة داخل الموقع (App Router):**

انسخ `nextjs-integration/app/magazine/page.tsx` إلى `app/magazine/page.tsx` في موقعك. يبقى عنوان الصفحة `/magazine` وتظهر المجلة بملء الشاشة.

إذا كان موقعك يستخدم Pages Router، ضع المحتوى نفسه في `pages/magazine.tsx`، واحذف سطر `metadata` واستخدم `<Head>` بدلًا منه.

**الخيار (ب) — تحويل مباشر بلا iframe:**

في `next.config` فعّل `redirects()` الموجودة في `nextjs-integration/next.config.example.mjs`، فيصبح `/magazine` يحوّل إلى `/ayman-magazine/index.html`.

> استخدم **أحد** الخيارين فقط، لا الاثنين معًا.

### 3) (اختياري) التخزين المؤقت

انسخ `headers()` من `next.config.example.mjs` إلى `next.config` لتخزين الصور والخطوط في المتصفح لمدة طويلة.

### 4) الربط من صفحات موقعك

```tsx
<a href="/magazine">تصفّح المجلة</a>
{/* أو مباشرة إلى قسم معيّن: */}
<a href="/ayman-magazine/index.html#aywise">مشروع AYWISE</a>
```

ثم انشر كالمعتاد (`git push` أو `vercel deploy`). لا يلزم أي إعداد إضافي على Vercel.

## التحكم

| الإجراء | الكمبيوتر | الجوال |
|---|---|---|
| الصفحة التالية | ← أو PageDown، أو النقر على الصفحة اليسرى، أو سحب طرفها | السحب جانبيًا أو زر ‹ |
| الصفحة السابقة | → أو PageUp، أو النقر على الصفحة اليمنى | السحب جانبيًا أو زر › |
| الغلاف / النهاية | Home / End | من زر «الفهرس» |
| تكبير عمل | النقر على الصورة أو زر العدسة، ثم العجلة أو النقر المزدوج أو + و − | النقر ثم التكبير بإصبعين |

تتحوّل المجلة تلقائيًا بين وضع الكتاب ووضع الصفحة الواحدة حسب عرض الشاشة. الحد هو 760px تقريبًا، ويُضبط من الدالة `pickMode()` في `js/magazine.js`.

## ملاحظات تقنية

- **لا اعتماد على أي خدمة خارجية:** المجلة لا تحتاج Claude ولا أي ملفات مؤقتة أو حسابات. الطلب الخارجي الوحيد هو الخطوط من Google، ويختفي بعد تشغيل `download-fonts.mjs`.
- **المتصفحات:** تعمل على Chrome وEdge وSafari وFirefox الحديثة، وعلى iOS وAndroid. تستخدم `container queries` و`3D transforms` المدعومة فيها جميعًا.
- **إمكانية الوصول:** تحترم المجلة إعداد «تقليل الحركة» في النظام، فيصبح التقليب فوريًا.
- **الحجم:** نحو 6 ميغابايت، معظمها الصور الأصلية.
- **تعديل النصوص:** كل نصوص الصفحات موجودة في `index.html` داخل `<div id="pages">`، وكل صفحة عنصر `<section class="pg">`.
- **ترقيم الصفحات والفهرس:** يُحسبان تلقائيًا. عدد صفحات نسخة الكمبيوتر يجب أن يبقى زوجيًا. الصفحات المعلّمة `data-only="desktop"` تظهر على الكمبيوتر فقط، و`data-only="mobile"` على الجوال فقط، وتُستخدم للأعمال العريضة الممتدة على صفحتين.
